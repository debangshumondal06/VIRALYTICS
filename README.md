# VIRALYTICS (Vercel edition)
Static site + 3 serverless functions in `api/`. No Python backend.
Vercel: Framework Preset = Other (no build command, no output directory).
Environment variables: GEMINI_API_KEY (your key), APP_PASSWORD (a long password you choose), optional GEMINI_MODEL.
After deploying: open the site, Settings, enter APP_PASSWORD, press Connect.
